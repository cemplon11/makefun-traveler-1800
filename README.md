# One Sentence for a Traveler from 1800

A single sentence, at most 200 characters, explaining the modern internet to
someone who has just arrived from the year 1800 — built only from things they
already know: a post road, a letter, a library, a shop, a newspaper.

The sentence:

> Imagine a post road of copper wire where a letter flies in a blink to any town on Earth, and every library and shop and newspaper lies open upon your desk at home.

## Run it

```sh
python3 main.py
```

Writes the sentence (163 characters, exactly one sentence) to
`/output/entry.txt`. Pure Python standard library, deterministic — repeated
runs produce byte-identical output.
